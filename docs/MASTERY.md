# Mastery scoring

Each lesson's exercise weights equal its difficulty: beginner = 1, intermediate = 2, challenge = 3. The latest correct attempt earns the full weight when no hint or solution was used. An assisted correct attempt earns half weight. An incorrect latest attempt earns no weight. The score is earned weight divided by total available weight, rounded to a percentage.

Completing or opening a lesson does not increase mastery. Attempt accuracy is reported separately and uses all recorded attempts so students can see both learning progress and persistence.
